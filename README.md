# Diabetes Prediction MLOps Project

## Project Overview

This project predicts whether a patient is diabetic or non-diabetic using machine learning models trained on medical data.

The project includes:

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Machine learning model training
- Model evaluation
- FastAPI deployment
- GitHub version control

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- FastAPI
- Joblib

```bash

```

```bash
pip install -r requirements.txt
```
